# Phoenix 足球分析 App

Phoenix 是以 Streamlit、真實全場賽果及可追溯公開來源建立的足球分析工具。574隊球員／教練名冊、天氣修正及手動賠率分析互相分開，沒有因缺少資料而虛構比分或球員數據。

## 手動賠率安全政策

本專案採用**手動填賠率，合法安全，無自動爬蟲**的設計。VALUE／陰盤功能只分析使用者輸入的十進制賠率，不連接香港賽馬會或任何莊家接口，也不會自動抓取馬會水位。

陰盤警告只是模型與隱含機率的風險提示，不是投注保證；使用者應自行核對正選、傷病、賽事時間及盤口是否一致。

## 啟動

```bash
streamlit run app.py
```

主App會讀取 `assets/data/final_574_squads_with_sources.json`。每週名冊更新workflow會將後台驗證檔同步至App資產目錄。
